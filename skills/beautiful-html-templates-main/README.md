# beautiful-html-templates（精美 HTML 模板库）

一个可复用的 HTML 幻灯片模板库，专为编程智能体设计——任何编码代理都能自动选出最合适的模板，替用户生成一套精美的幻灯片。

使用本库的智能体应先阅读 [`AGENTS.md`](./AGENTS.md)。那是操作手册：讲解如何读取 `index.json`、将用户需求与模板匹配、克隆模板并适配内容。

## 快速开始

将以下内容复制给你的编码智能体：

```
Clone https://github.com/zarazhangrui/beautiful-html-templates and follow the instructions in AGENTS.md to build me a beautiful HTML slide deck.
```

## 模板画廊

共 34 套模板。每套模板展示三张幻灯片（封面·中间·后段），呈现各视觉系统在不同布局下的效果。点击任意模板名称可在 GitHub 打开对应文件夹——HTML 文件、元数据及配套素材均在其中。
